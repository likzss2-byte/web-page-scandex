# ScanDex

Página web de presentación de **ScanDex**, una aplicación que escanea peluches, imagenes, cartas, e (estilo Pokédex).

## Contenido

- **Sobre la aplicación**: qué hace la app y sus funciones.
- **Sobre nosotros**: información del equipo.
- **Descarga**: acceso para obtener la app.

## Estructura

.
├── index.html       # Página principal
├── css/
│   └── estilos.css  # Estilos
└── README.md


## Cómo usarlo

No requiere instalación. Abre `index.html` en tu navegador.
